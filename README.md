# The MacDolphin
The MacDolphin is a macro-pad, but in the shape of a dolphin :)

## The file-layout
- 3d_model.zip - contains the .blend file
- MacDolphin-bom(1).csv - contains the BOM with links
- ger.zip - contains the gerber file to the PCB
- macdolph.step - contains 3d model (but different format from the 3d_model.zip)
